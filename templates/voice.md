# Voice file

Every Liftli writing skill reads this file before it writes. Keep it short and
true. Two minutes of honest answers here beat any prompt.

Save it as `.liftli/voice.md` in a project (applies there only) or
`~/.liftli/voice.md` (applies everywhere). The `substack-voice` skill can fill
it in for you from three of your own pieces. It is the same file Liftli's
LinkedIn skills read, so one file serves both.
